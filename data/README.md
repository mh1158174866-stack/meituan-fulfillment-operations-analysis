# 数据目录

此目录只保存数据获取规则，不保存或重新分发官方数据。

## 本地目录

- `data/downloads/`：官方 ZIP 或临时下载文件，全部被 Git 忽略；
- `data/raw/`：解压后的四张官方 CSV，全部被 Git 忽略。

两个目录中的 `.gitkeep` 只是保留目录结构。不要强制添加被忽略的数据文件。

## 允许公开的内容

- 官方下载页面和文件名；
- 文件字节数和 SHA-256；
- 字段名、推断类型和字段说明；
- 行数、缺失率、重复数、覆盖率等聚合统计；
- 不含明细记录的质量结论。

## 禁止提交的内容

- 原始 CSV、ZIP 和官方 PDF；
- 原始订单、运单、骑手、波次等 ID；
- 经纬度、地址或其他精确位置；
- 任意可还原单个骑手、订单或运单行为序列的明细；
- 从原始数据派生但仍可回溯个体的 CSV、JSON 或 Parquet。

下载和使用数据即表示同意美团官方仓库的 CC BY-NC 4.0、非商业用途、署名及不得未经许可向第三方分发等要求。
