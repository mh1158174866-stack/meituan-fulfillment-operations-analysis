# 数据许可与使用边界

## 来源

数据由美团在官方 GitHub 仓库发布：

<https://github.com/meituan/Meituan-INFORMS-TSL-Research-Challenge>

官方许可文本：

<https://github.com/meituan/Meituan-INFORMS-TSL-Research-Challenge/blob/main/License.txt>

## 适用要求

依据官方许可说明，数据集按 CC BY-NC 4.0 提供，并附带以下项目级约束：

- 仅用于非商业用途，例如学术研究、教学或科学出版；
- 未经许可不得向第三方分发数据集；
- 不得将数据集或其衍生作品用于商业利益；
- 公开发表基于数据集的研究时，应注明“本研究由美团提供数据支持”或官方英文致谢。

本仓库不复制官方许可原文；使用者应在每次下载前阅读官方最新文本。若本说明与官方文本冲突，以官方文本为准。

## 本仓库做法

- 下载脚本只指向美团官方仓库；
- 原始文件保存在 Git 忽略目录，不随代码分发；
- 公开产物只包含字段说明、文件规模、聚合统计、质量结论和官方下载指引；
- 外部报告中的参考数值仅可标为外部对照，不得写成本项目成果。
