# 数据许可与公开发布说明

## 官方约束

美团官方仓库声明该数据集按 CC BY-NC 4.0 提供，仅限非商业用途；未经许可不得向第三方分发数据集。INFORMS 挑战页面也要求下载者不得通过其他渠道公开或共享数据。

## 本仓库处理方式

- 原始 CSV、压缩包和本地数据库位于 Git 忽略目录。
- 不提交订单、运单、骑手、商家、用户、波次等原始标识符。
- 不提交经纬度、地址或可还原个体轨迹/行为序列的明细。
- 仅发布下载脚本/指引、字段说明、数据规模、聚合 KPI、脱敏图表和复现代码。
- 任何拟公开 CSV、JSON 或 Parquet 必须先通过自动隐私扫描和人工复核。
