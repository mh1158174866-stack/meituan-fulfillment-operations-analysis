# 隐私与公开产物边界

## 核心原则

原始数据只在本地只读验收。公开产物不得包含原始 ID、坐标或可还原个体行为的序列。

## 高风险字段与内容

- 订单、运单、骑手、波次等标识符；
- 收发位置、经纬度、地址和精确地理编码；
- 单条事件时间线或能按个体重排的时间戳明细；
- 小样本切片中可唯一定位个体的组合字段；
- 数据文件、压缩包、官方 PDF 和数据行样例。

## 公开前检查

1. 自动扫描文件名、表头和正文中的敏感字段模式；
2. 检查 CSV、JSON、Parquet 等机器可读产物是否确有必要；
3. 人工复核暂存差异，只允许聚合数值和质量结论；
4. 用 `git check-ignore` 和 `git diff --cached` 确认原始文件未进入提交。

即使统计结果通过自动扫描，也不得发布可由稀疏组合推断单个订单、运单或骑手的信息。
